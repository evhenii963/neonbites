# Pocket Option OTC Currency Signal Scanner

Це перша робоча версія **сигнального сканера**, не торговий робот-автовиконавець.

## Що робить
- Отримує актуальний каталог OTC-інструментів через незалежний read-only сервіс OTCharts.
- Відбирає валютні пари формату `EURUSD_otc` (акції, криптовалюти та інші інструменти відсіюються).
- Перевіряє 5-хвилинні свічки.
- Рахує EMA 9/21, RSI 14, MACD та просте підтвердження свічкою.
- Виводить BUY / SELL / WAIT або SKIP.
- За замовчуванням повторює сканування кожні 20 хвилин.

## Важливі обмеження
1. Pocket Option не публікує офіційний API для розробників. Цей сканер читає дані через незалежний сервіс OTCharts; це не офіційна інтеграція і не гарантує повної тотожності даних у торговому терміналі.
2. Ключ OTCharts — окремий ключ сервісу даних, НЕ пароль і НЕ ключ Pocket Option. Ніколи не вводь у програму пароль Pocket Option, cookie або SSID.
3. Безкоштовний тариф OTCharts обмежує доступ п'ятьма інструментами та початковою квотою запитів. Для повного каталогу потрібен тариф, що відкриває весь OTC book. Перевір актуальні умови й ціну на сайті постачальника перед оплатою.
4. Сканування всіх валютних пар кожні 20 хвилин може потребувати приблизно 72 сканувань × кількість пар запитів на день. Перевір квоту свого тарифу.
5. Оцінка 3/4 — це кількість збігів індикаторів, а не ймовірність виграшу. Стратегія не має підтвердженої прибутковості. Спочатку тестуй лише на демо.

## Встановлення на Windows
1. Встанови Python 3 з https://www.python.org/downloads/ і під час інсталяції постав прапорець **Add Python to PATH**.
2. Розпакуй ZIP у папку, наприклад `Desktop\PocketOTCScanner`.
3. Відкрий цю папку, натисни в адресному рядку Провідника, введи `cmd` і натисни Enter.
4. Виконай:
   `py -m pip install -r requirements.txt`
5. Запусти:
   `py pocket_otc_scanner.py`
6. Створи ключ OTCharts на https://otcharts.com/account (сервіс сторонній, не Pocket Option) і встав його у вікно консолі. Ввід буде прихований.

Щоб зупинити сканер, натисни `Ctrl+C`.

## Перший тест
Переконайся, що символи збігаються з доступними парами в Pocket Option, що ціна не застаріла, а сигнали не пропускають інструменти з пропусками в даних. Не використовуй його для автоматичного відкриття угод.
